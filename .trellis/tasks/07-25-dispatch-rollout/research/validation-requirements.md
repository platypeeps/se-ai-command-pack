# Research: Validation requirements for dispatch sections

- **Query**: What gates must a dispatch section satisfy — neutrality lint, section validation, version/changelog/generator-check — and how do the pilots pass them today.
- **Scope**: internal
- **Date**: 2026-08-05

## (a) Neutrality lint (framework-neutrality)

- Defined in `.github/scripts/generate-skill-surfaces.py:140-142`:
  ```python
  BANNED_PHRASE_PATTERN = re.compile(
      r"\b(Claude|Cowork|Codex|Copilot|Gemini|ChatGPT|OpenAI|Anthropic|Amp)\b"
  )
  ```
- Enforced during skill validation at `generate-skill-surfaces.py:283-288`: scans the whole file `text`; any brand-word match produces the error "framework-neutrality lint: replace brand names {…} with capability phrasing (e.g. 'your web search tooling')".
- **Rule for dispatch bodies**: no host/product/vendor brand names. Use capability phrasing ("sub-agent dispatch platforms", "your web search tooling", "the parent context"). Lowercase dotted paths like `.claude/skills` are allowed per the comment at `:137-139`; brand words are not. The pilot sections satisfy this (no brand words in se-research:73-109 / se-fact-check:85-116).

## (b) Section validation for dispatch sections

- **There is NO dispatch-section-specific structural check.** `grep` for `dispatch|Sub-agent|orchestrator|worker` across `generate-skill-surfaces.py` and `tests/` returns no assertions; the dispatch section is unconstrained prose.
- The only relevant structural gate is `REQUIRED_SECTIONS` ordering (`generate-skill-surfaces.py:90-96`):
  ```
  "## When to use", "## Arguments", "## Workflow", "## Safety rules", "## Final report"
  ```
  Validation loop at `:269-277` finds each required heading by `\n{section}\n` and errors only if a required section is missing or **out of order**. Non-required sections (like `## Sub-agent dispatch`) interspersed between them are allowed. Inserting between `## Workflow` and `## Safety rules` keeps the order valid.
- Additional body checks in the same validator: file must end with a newline (`:265-266`); body must open with an H1 (`:267-268`); argument-vocabulary check on the Arguments section (`:279-281`) — none affected by a dispatch section.
